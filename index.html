วิธีเปิดใช้งาน Cloud Firestore ใน Firebase Console (landshop-th):
  1. เข้าไปที่ Firebase Console → เลือกโปรเจกต์ landshop-th
  2. ไปที่เมนู Build → Firestore Database แล้วกด Create database (เลือก Region asia-southeast1)
  3. ไปที่แท็บ Rules ของ Firestore แล้วคัดลอก Security Rules ด้านล่างไปวางแล้วกด Publish
  4. รีเฟรชหน้าเว็บ ระบบจะเชื่อมต่อและซิงก์ข้อมูลเข้า Firebase อัตโนมัติ (ระหว่างนี้ระบบบันทึกในเครื่องให้ไม่สูญหาย)

Firestore Security Rules แนะนำ (สำหรับวางใน Firebase Console)

เลือกใช้โหมดเริ่มต้นเพื่อให้ทั้งล็อกอินระบบและ Firebase Auth บันทึกข้อมูลได้ทันที

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // อนุญาตให้อ่านและเขียนสำหรับคอลเลกชันหลักของ LandShop TH
    // (หากต้องการล็อกเฉพาะ Firebase Auth ให้เปลี่ยน allow write เป็น: if request.auth != null;)
    match /listings/{docId} {
      allow read, write: if true;
    }
    match /banners/{docId} {
      allow read, write: if true;
    }
    match /settings/{docId} {
      allow read, write: if true;
    }
  }
}
